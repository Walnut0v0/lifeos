# 分类与专注怎么用

1. 打开LifeOS，点「应用分类与白名单」。原来选的白名单会保留，并显示「单独允许」。
2. 勾类别左边的方框，整类允许；勾应用左边的方框，只改这个应用。单应用选择优先。「跟随类别」可取消单应用例外。
3. 自动分类不合适，点应用右侧「改分类」，选正确类别。刷新和重新打开后仍保留；「恢复自动分类」取消人工修正。名称推测会提示确认。
4. 点「完成」，选时长，点「开始专注」。计时页和受限应用上方的计时画面都能打开白名单应用；点LifeOS图标或通知返回计时。
5. 正常提前结束：点「申请结束专注」，等10秒，再点确认。点「继续专注」取消。如果误拦必要操作，直接点「应急解除」。

不需要为了本轮测试打开系统设置。专注页已去掉设置快捷按钮。当前普通应用仍不能保证防止从系统强停；必要系统功能和全部系统应用保持放行。

新安装后被扫描到的应用默认单独关闭，需你确认允许或选择跟随类别。本次专注只管控开始时扫描到的应用；新装应用在下次开始纳入。单次1–30分钟，不能保证分屏、小窗、分身或厂商回收后始终生效。锁屏后计时继续，再打开LifeOS仍是原计时；不会代替系统锁屏或保证解锁直接进入LifeOS。
