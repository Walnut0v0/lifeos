# 在线计划版怎么用（v0.4.0-alpha）

本轮交付两个包：online在线开发版、lab离线验证版。同一应用ID和本地签名，互相覆盖安装；不同时安装成两个应用，以保留原白名单及授权。在线包新增必要网络权限，Lab仍无INTERNET。

## 手机上
1. 安装online包，打开「计划、统计与申请调整」。原来的分类和白名单仍在。
2. 私有数据源连接完成后，先检查版本和未来任务，再勾「按已缓存计划自动执行」。之后无需点开始：到点自动判断，剩余时间取任务结束时间减当前时间。锁屏不点亮，解锁重新判断。应急结束后本段不会重启，可以明确点恢复。
3. 「全天手机使用统计」有独立采集、日汇总上传、详细区间上传开关。初始全关；开启后从当时开始采集，可预览上传内容、选择保留1/7/30天，分别删除本机或私有服务数据。统计出错不阻断计划同步。
4. 需要改计划时，复制调整申请，点「打开ChatGPT申请调整」。只启动ChatGPT，不读取、填写或发送聊天。从此入口打开时临时允许ChatGPT最多5分钟；返回LifeOS后检查新版本。

当前手机尚未安装/实测本轮版本，按用户要求先完成开发和安装包。后台更新不是实时推送：WorkManager周期最短15分钟，系统可能延迟；应用打开、网络恢复和可观测解锁会触发节流补同步。缓存到点执行不依赖网络，过期/无任务/未知模式放行。

## 当前连接边界
项目内没有手机Google OAuth配置或现成Focus Exchange表，因此按最新任务允许的备用路径实现受控HTTPS SyncAdapter，未把私有Sheet发布到Web。Google登录/选表没有实现或假装成功。实际HTTPS目的地和规划端发布工具仍需接入验证；不能把本地JSON测试当作已连通普通ChatGPT聊天。

如果你继续连接手机，我可以直接通过已授权ADB配置debug包，不需要你输入长地址/凭证。这里保留的手工连接按钮用于自主配置与故障诊断。

## 私有交换服务（开发者）
运行 `./tools/start-exchange.ps1` 启动仅127.0.0.1:8787监听的服务。`-Tunnel` 可使用已下载且签名有效的cloudflared建立临时HTTPS开发通道；本轮没有开启公网通道。正式使用应换稳定HTTPS主机/反向代理。临时通道地址每次变化、电脑关机即不可用，没有在线保障。

凭证自动生成在忽略目录work/private/exchange/config.json，Windows私有目录限制为当前用户和SYSTEM。phone_token只能读计划、写/删统计；planner_token才能发布计划、读取统计。APK中没有预置凭证。手机凭证由Android Keystore AES-GCM保护。不要把该目录、真实计划或日志提交GitHub。

连接手机前确认已安装online debug包，再运行 `py -3 tools/configure-device.py`；只配置私有HTTPS连接，不开启自动执行或采集。`./tools/stop-exchange.ps1` 只停止经路径校验的本项目服务进程。

服务GET/PUT /v1/plan，完整快照、递增revision、无重叠、显式偏移时间、最长8天有效期/单任务24小时、未知模式放行；空tasks发布取消。不同内容不能复用revision，错误版本不会替换有效缓存。客户端不跟随HTTP重定向、不接受明文HTTP、不跳过证书验证。桥接服务只在环回提供HTTP，公网必须由可信HTTPS代理承接。

统计PUT /v1/usage按日期+时区+随机设备代号幂等覆盖；可选PUT /v1/intervals分批，收齐后原子替换当日详细区间。规划端GET /v1/usage默认最近3份日汇总，可按date查询；GET /v1/intervals按日期每页200条。DELETE /v1/usage删除本服务的统计。此参考服务按单用户、单手机凭证部署，不是多租户托管产品。

## 让规划端发布
bridge/openapi.json是私有交换API描述，server为占位符。接入授权工具时替换成实际私有HTTPS地址，使用planner凭证；手机使用不同的phone凭证。规划工具先GET当前版本，再PUT完整新版本，至少发布今日和次日，空计划显式取消。私有Planning State仍是规划主数据源，不修改既有23:30自动化。

普通聊天不会因安装APK就获得写入这个接口的权限。ChatGPT授权工具/自定义GPT Action的账号端接入、真实写入与手机自动拉取仍待后续验证；不需要把OpenAI API key塞进手机。

## 尚未验收
A1/A2真机两段计划、锁屏/断网/重启/修订/取消；B1与人工及系统统计对照、完整日覆盖误差；B2云端回读与日终补齐；C1实际ChatGPT打开与返回更新。当前统计按最近缓存计划和当前分类/白名单推算，不代替历史策略审计。实际有效管控时长尚未测量，输出null；不会把屏幕熄灭当学习完成。分屏、小窗和后台回收局限继续保留。

数据源更换会关闭自动执行并清除旧源快照，避免不同源revision互相阻塞；上传许可也会重置。旧源在途响应在快照锁内校验来源，不允许写回新源缓存。强制刷新/ChatGPT返回会替换排队中的重试，避免被旧退避任务延后。此状态转换源码已复核，仍待真机交互验证。
