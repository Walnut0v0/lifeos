# LifeOS Focus 需求规格

## 目标
个人 Android 手机专注管理，与 LifeOS 每日规划/复盘联动。在计划时段自动限制无关应用，降低主动开启计时的负担。目标设备荣耀 MagicOS 11；Android API Level、机型差异由真机确认。

## 功能需求
- R01 手动专注：设置开始、时长、模式，显示剩余时间，允许安全退出。
- R02 计划专注：按起止时间自动开始/结束，支持连续任务、休息、跨日、提前完成、推迟、延长、计划变更；断网执行有效本地计划。冲突、过期、无效计划明确提示并安全放行。
- R03 应用扫描：通过 PackageManager 查询有启动入口的应用，展示名称、包名、图标、系统分类及系统/第三方属性；支持刷新、搜索、新装/卸载变化。优先使用 launcher intent queries，不默认申请 QUERY_ALL_PACKAGES。
- R04 本地自动分类：用户历史修正 > 内置包名库 > ApplicationInfo.category > 名称/包名规则 > 待分类。初始类别：学习教育、科研工具、办公效率、通信社交、影音娱乐、游戏、购物消费、生活服务、系统工具、金融支付、出行导航、待分类。用户可重新分类，覆盖自动结果；重新扫描不得覆盖人工修正。低置信度明确标记。后期可选择将清单交给外部辅助分类，但仅发送获授权的应用元数据，不发送内容。
- R05 模式与白名单：学习、科研、事务、生活、睡眠、自由等可自定义模式；类别级允许规则与单应用例外（安全白名单 > 用户应用规则 > 类别规则）。新应用默认待确认；安全关键/未知系统窗口不误拦截。
- R06 应用管控：识别应用切换并对受限目标返回桌面或显示拦截层；到点时处理当前已打开的受限应用；覆盖桌面、最近任务、通知跳转、深链、分屏、小窗、分身等场景，记录局限。普通 Android 应用不保证阻止进程启动。
- R07 约束强度：普通退出、延迟退出、严格模式（常规退出增加摩擦）、计划锁定；始终保留清晰应急解除及系统设置、撤销授权、卸载路径。支持单应用限时通行，结束后恢复原策略。Phase 01 不实施严格锁定。
- R08 统计：专注计划时长、有效管控时长、服务异常区间、拦截次数、提前退出、临时通行、用户确认完成状态。可选应用使用记录（应用名称/包名、开始/结束、时长、事件类型）；不记录页面内容。明确管控时间并不等于学习时间。数据查看、选择导出、删除、保留期限设置。
- R09 LifeOS 联动：获取日程及版本，校验后原子更新本地计划，回传用户授权的统计及可选应用列表、分类、详细使用记录。数据源可替换（Sheets/Calendar/其他）；支持离线缓存和手动导入，认证、安全传输详见 PRIVACY。
- R10 权限诊断和恢复：设备/API 版本、服务连接、精确闹钟、通知、电池优化、启动管理提示；开机、解锁、服务重连、时区/时间调整后重新判定状态；权限失效明确提示，禁止绕过系统权限。
- R11 UI：专注首页（当前任务、模式、剩余时间、下一任务、服务状态、应急通行）；计划页；应用分类/白名单配置；统计；设置与权限自检。中文优先，清晰克制。
- R12 安全与隐私：遵守 PRIVACY.md；仅获取必要元数据，禁止读取消息正文等内容，不阻止系统安全操作。

## 非功能需求
本地离线可执行、最小权限、低资源占用、可解释规则、可测试、可恢复、故障放行。时间误差、拦截延迟及系统存活率以 Phase 01 实测为依据，不预先承诺全部场景可行。优先个人侧载使用，不要求上架或付费服务器。

## R13 防冲动退出与完整授权诊断
专注期间评估设置、多任务、后台清理等退出路径，尽可能通过系统支持的可逆机制减少冲动退出。区分系统设置入口提示、用户手动多任务加锁、系统屏幕固定及企业受管设备模式；必须保留明确应急解除和最终设备控制权。第一阶段完整实测范围见 tests/PHASE01_CAPABILITY_MATRIX.md，包含使用情况访问、开机自启、荣耀启动管理三项、电池优化豁免、前台服务、覆盖层、通知等所有相关候选能力。禁止申请与项目无关的权限。
