# v0.1.1：只复测覆盖层

这次只需要测一次，不用重新跑其他项目。

1. 安装 `lifeos-focus-lab-v0.1.1.apk`，核对软件顶部为v0.1.1。使用本次本地v0.1.0包的用户可尝试直接覆盖安装；如果旧包来自CI，签名可能不同，先保留需要的报告，再按系统提示处理。
2. 保留一个非关键第三方目标，在「计时」页选B，持续填1分钟，开始测试。
3. 打开目标应用，观察画面能否持续到约10秒。这个版本仍有10秒实验上限，到时停止整场测试；目前还不是持续到专注结束的正式界面。
4. 如果仍在1–2秒消失，回「计时」页，把“覆盖层最近情况”后面的中文原文发来，同时说明倒计时是否继续。不必抄包名或代码。
5. 点顶部红色按钮结束测试。

新增识别会把当前事件的窗口ID与自己创建的覆盖层ID比较。ID通过公开API给自有View建立临时事件获取，不读取任何外部节点、屏幕文字或事件source；未知窗口和系统安全界面仍放行。此次是针对性修正与诊断增强，尚不能确认用户手机上的根因已经修复。
