# 隐私、安全及数据治理（强制规范）

## 数据分类和共享许可
用户允许应用安装清单、分类结果及详细使用记录在不泄露个人内容的前提下发送/同步。应用元数据和时间序列仍可能揭示习惯、健康或其他私人情况，因此视为受控个人数据，而非可任意公开的数据。

|数据|采集/保存|共享|
|---|---|---|
|应用名称、包名、系统分类、用户分类|本地允许；图标从系统资源读取|明确授权后可发送至用户指定私有目的地|
|前台包名、使用起止与时长、拦截记录|实时判断允许；完整历史为可选功能，默认关闭，正式版用户开启后可存储|允许用户选择详细或聚合记录并预览后授权同步|
|任务时段、任务标题、执行统计|必要字段；标题尽量简化|授权后同步至指定 LifeOS 数据源|
|测试日志|必要事件、时间偏差、错误码；默认代号|公共仓库仅经检查的脱敏数据|
|消息、通知正文、屏幕文字、窗口节点、输入及密码、截图/录屏、联系人、通话记录、定位、音视频、硬件唯一标识|禁止采集、读取、存储|禁止发送|
|认证凭证、签名私钥|系统安全存储，最小作用域|禁止写入仓库、日志及导出|

共享必须有明确目的地、数据范围、授权开关、可撤销、可删除与导出预览。应用清单/详细历史可发送至受控私有表格、服务或用户主动提供给 ChatGPT；不能默认发至公开 GitHub。公共仓库只提交通用代码、虚拟样本、审查通过的脱敏报告。不得将个人内容混入日志、诊断、异常消息。同步关闭后立即停止后续上传。

## Phase 01
完全离线：最终合并 Manifest 不得有 INTERNET 权限；不得集成广告、分析、遥测或崩溃上报 SDK。扫描结果默认仅展示；测试目标与有效时段可本地保存，诊断日志限量、可清除。报告手动导出，默认代号；允许用户主动选择导出应用清单/分类等元数据并预览，不包含私密内容。此阶段不做网络同步和持续使用历史采集。

## AccessibilityService 白名单能力
canRetrieveWindowContent=false；不声明截图、手势能力（或显式 false，依 SDK 支持）。仅订阅必要的窗口切换事件（优先 TYPE_WINDOW_STATE_CHANGED）；仅取必要的 event.packageName 和时间/事件类型。不读取 event.text、event.source、窗口节点、getRootInActiveWindow()、输入或通知内容。不订阅文本变化等无关事件。仅必要的返回桌面和自有覆盖层；不得自动操作其他应用或授权页面。

## 设备安全
电话及紧急呼叫、锁屏/解锁、桌面、输入法、系统设置/权限、系统必要界面、应用自身始终放行。不干预权限撤销、卸载、强制停止。不使用 Root、Device Owner、隐藏进程或阻止设置访问；第一阶段仅测试显式选中的非关键应用，限制时长有限，提供全局停止按钮并尽可能提供通知停止入口。通知不可用时仍能从自身应用停止。异常、权限失效、状态未知、配置损坏均 Fail-open；避免拦截循环和覆盖锁屏/权限/紧急页面。

## 存储、网络、审计
应用私有目录，关闭或排除不必要备份和设备迁移；用户可查看、清除及设定保留期。后续 HTTPS、OAuth 最小授权、Keystore 保护密钥，不硬编码令牌。第三方 SDK 最小化；合并 Manifest、最终 APK 权限、代码扫描、日志与导出样例均纳入审查。仓库禁止真实配置、个人日程、真实使用记录、签名文件和凭证；即使仓库私有也不提交秘密。公开仓库可保留通用文档，建议转私有但不由开发代理擅自更改。

## 扩展授权验证边界
Phase 01 可独立申请使用情况访问权限进行短时本地使用元数据测量，可选悬浮窗、合法前台服务、系统屏幕固定等仅在明确用户选择后试验；默认关闭，提供撤销说明。普通设置入口只测试识别及可立即解除的提示/确认；权限管理、系统安全和应急功能始终可达，不封锁导航或系统界面。允许测试用户手动多任务卡片加锁、启动管理三项及电池优化豁免；不得自动修改。Device Owner/DPC 仅调查，不在主力手机配置；另行授权后可在专用测试设备验证。以上不放宽禁止读取私人内容、联网和故障放行规范。
